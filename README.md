# مُحسِّن Windows

أداة PowerShell لشرح وتطبيق مجموعة مختارة من إعدادات Windows المتعلقة بالأداء والخصوصية والطاقة والخدمات وبرامج بدء التشغيل. تعمل على Windows 10 إصدار 2004 أو أحدث، وWindows 11، وتتطلب صلاحيات المسؤول.

## روابط مباشرة

- [تنزيل ملفات المشروع ZIP](https://github.com/MohamedJafer11314/mytweak/archive/refs/heads/main.zip)
- [فتح السكربت لمراجعته](https://github.com/MohamedJafer11314/mytweak/blob/main/full_optimize.ps1)
- [مراجعة مشغّل الواجهة](launch_optimizer.ps1)
- [شرح التعديلات بالعربية](TWEAKS_AR.md)
- [واجهة Windows الرسومية](cpp_ui)

راجع ملفات المشروع قبل تشغيله. أمر التشغيل المباشر ينزّل الواجهة التنفيذية والسكربت المطابق من GitHub، ثم يفتح الواجهة؛ لا يطبق تغييرات Windows إلا بعد اختيار التشغيل والموافقة على الخطة.

## التشغيل

### تشغيل مباشر

افتح Windows PowerShell ثم نفّذ الأمر التالي؛ لا تحتاج إلى تشغيل PowerShell كمسؤول لفتح الواجهة:

```powershell
irm https://raw.githubusercontent.com/MohamedJafer11314/mytweak/main/launch_optimizer.ps1 | iex
```

ينزّل الأمر الواجهة العربية والسكربت المطابق لها من GitHub ويفتح الواجهة. عند الضغط على التشغيل، يطلب Windows صلاحيات المسؤول ثم يعرض السكربت خطة التغييرات وتأكيدها. هذا الأسلوب ينفّذ ملفات من الإنترنت؛ راجع المصدر ولا تستخدمه إلا إذا كنت تثق بالمستودع. لتشغيل نسخة نزلتها يدويًا ومراجعتها، اتبع الخطوات التالية.

### تشغيل النسخة المنزّلة

بعد تنزيل ZIP وفك ضغطه، افتح Windows PowerShell كمسؤول وانتقل إلى مجلد المشروع المستخرج. عند استخدام موقع التنزيل الافتراضي سيكون المسار غالبًا:

```powershell
Set-Location "$HOME\Downloads\mytweak-main"
Test-Path .\full_optimize.ps1
```

يجب أن يعرض الأمر `Test-Path` القيمة `True`. إذا فككت الضغط في مكان آخر، استبدل المسار أعلاه بمسار مجلد `mytweak-main` لديك. بعد ذلك شغّل:

تشغيل `full_optimize.ps1` يدويًا يفتح أداة اختيار PowerShell القديمة. استخدم أمر التشغيل المباشر أعلاه لفتح واجهة C++ العربية الجديدة.

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\full_optimize.ps1
```

يعرض السكربت خطة التغييرات ويطلب تأكيدك قبل تطبيقها. يحاول إنشاء نقطة استعادة ويحفظ نسخة من إعدادات محددة في مجلد على سطح المكتب. قد تتطلب بعض التغييرات تسجيل الخروج أو إعادة التشغيل.

## ملفات التحسين

- **آمن:** يقلل التعديلات الاختيارية؛ راجع المعاينة لأن تغييرات النظام الأساسية ما زالت تُعرض قبل التنفيذ.
- **متوازن:** إعداد عام. حذف تطبيقات المتجر وقائمة إزالة البرامج غير مفعّلين افتراضيًا.
- **مكثّف:** يطبق تغييرات إضافية؛ راجع كل بند في المعاينة قبل الموافقة.

يظل Windows Defender وWindows Update والجدار الناري والشبكة والصوت والرسوميات خارج قائمة التعطيل. لا يمكن لنسخة الاستعادة إعادة تثبيت التطبيقات المحذوفة أو التراجع تلقائيًا عن كل التغييرات؛ التفاصيل والقيود موضحة في [دليل التعديلات](TWEAKS_AR.md).

## الواجهة الرسومية

يوجد مشغّل عربي اختياري مبني بـ C++ Win32 داخل `cpp_ui`. رابط ZIP أعلاه يضم ملفات المشروع. لبناء الواجهة، افتح Developer Command Prompt for Visual Studio وشغّل `build_optimizer_ui.bat` داخل مجلد `cpp_ui`. يجب أن يكون `full_optimize.ps1` بجانب الملف التنفيذي عند تشغيله.

تحتوي الواجهة على زر **تويكات متقدمة** لضبط الخيارات قبل المعاينة، وزر **التطبيقات والتعريفات** لاختيار برامج عبر `winget` أو فتح صفحات الشركات الرسمية. صفحات الفئات الأخرى تعريفية؛ التغييرات الفعلية تظهر في خطة PowerShell قبل التنفيذ. راجع [تعليمات الواجهة](cpp_ui/README.md) و[شرح التعديلات](TWEAKS_AR.md).
