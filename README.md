# مُحسِّن Windows

أداة PowerShell لشرح وتطبيق مجموعة مختارة من إعدادات Windows المتعلقة بالأداء والخصوصية والطاقة والخدمات وبرامج بدء التشغيل. تعمل على Windows 10 إصدار 2004 أو أحدث، وWindows 11، وتتطلب صلاحيات المسؤول.

## روابط مباشرة

- [تنزيل ملفات المشروع ZIP](https://github.com/MohamedJafer11314/mytweak/archive/refs/heads/main.zip)
- [فتح السكربت لمراجعته](https://github.com/MohamedJafer11314/mytweak/blob/main/full_optimize.ps1)
- [شرح التعديلات بالعربية](TWEAKS_AR.md)
- [واجهة Windows الرسومية](cpp_ui)

نزّل ملفات المشروع وفك الضغط، ثم راجع `full_optimize.ps1` قبل تشغيله. لا تشغّل سكربتًا لم تراجعه، ولا تستخدم أسلوب تنزيل وتشغيل مباشر مثل `irm ... | iex`.

## التشغيل

افتح Windows PowerShell كمسؤول من مجلد المشروع، ثم شغّل:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\full_optimize.ps1
```

يعرض السكربت خطة التغييرات ويطلب تأكيدك قبل تطبيقها. يحاول إنشاء نقطة استعادة ويحفظ نسخة من إعدادات محددة في مجلد على سطح المكتب. قد تتطلب بعض التغييرات تسجيل الخروج أو إعادة التشغيل.

## ملفات التحسين

- **آمن:** يقلل التعديلات الاختيارية؛ راجع المعاينة لأن تغييرات النظام الأساسية ما زالت تُعرض قبل التنفيذ.
- **متوازن:** إعداد عام. حذف تطبيقات المتجر وقائمة إزالة البرامج غير مفعّلين افتراضيًا.
- **مكثّف:** يطبق تغييرات إضافية؛ راجع كل بند في المعاينة قبل الموافقة.

يظل Windows Defender وWindows Update والجدار الناري والشبكة والصوت والرسوميات خارج قائمة التعطيل. لا يمكن لنسخة الاستعادة إعادة تثبيت التطبيقات المحذوفة أو التراجع تلقائيًا عن كل التغييرات؛ التفاصيل والقيود موضحة في [دليل التعديلات](TWEAKS_AR.md).

## الواجهة الرسومية

يوجد مشغّل عربي اختياري مبني بـ C++ Win32 داخل `cpp_ui`. رابط ZIP أعلاه يضم ملفات المشروع. لبناء الواجهة، افتح Developer Command Prompt for Visual Studio وشغّل `build_optimizer_ui.bat` داخل مجلد `cpp_ui`. يجب أن يكون `full_optimize.ps1` بجانب الملف التنفيذي عند تشغيله.

صفحات الواجهة تعريفية؛ أما خيارات السكربت التفصيلية فتُعرض وتُؤكّد في PowerShell قبل التنفيذ. راجع [تعليمات الواجهة](cpp_ui/README.md).
