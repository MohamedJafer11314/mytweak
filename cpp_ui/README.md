# واجهة مُحسِّن Windows (C++ Win32)

هذا المجلد يحتوي على واجهة عربية لتشغيل `full_optimize.ps1` واختيار ملف التشغيل أو فتح مركز التنزيل والإعدادات المتقدمة.

## البناء

1. افتح Developer Command Prompt for Visual Studio.
2. شغّل `build_optimizer_ui.bat`.
3. سينتج الملف `OptimizerUI.exe`.

ضع `full_optimize.ps1` بجانب الملف التنفيذي. عند الضغط على زر التشغيل، تفتح الواجهة PowerShell بصلاحيات المسؤول وتمرّر ملف التحسين المختار. يعرض السكربت بعد ذلك خطة التغييرات ويطلب التأكيد.

## نطاق الواجهة

صفحات الفئات تشرح وظائف السكربت. استخدم **تويكات متقدمة** لتحديد إعدادات الأداء والخصوصية قبل معاينة الخطة، أو **التطبيقات والتعريفات** لاختيار برامج `winget` وفتح صفحات الشركات الرسمية. راجع [دليل التعديلات بالعربية](../TWEAKS_AR.md) وتفاصيل الخطة في PowerShell قبل التنفيذ.
